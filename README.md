# TrayTranslator — переводчик сообщений из системного трея (Alt+E)

Напишите сообщение в любом поле ввода (Telegram, WhatsApp, Discord, браузер, Word…) и нажмите
**Alt+E**. Текст сам выделится, переведётся в фоне и **заменится переводом прямо на месте**:

```
Привет, как дела?   →  Alt+E  →   Hi, how are you?
```

* **Без браузера.** Перевод идёт фоновым запросом к Google Translate, ключ API не нужен.
  Окон нет, программа видна только иконкой в трее.
* **Сам выделяет текст.** Если вы ничего не выделили, переводится всё содержимое поля. Если
  выделили часть текста, переводится только она.
* **Учится на ваших сообщениях.** Каждый перевод запоминается. Когда вы снова пишете «Привет»,
  готовый «Hello» подставляется мгновенно и без интернета. Длинные сообщения собираются из уже
  выученных предложений.
* **Понимает направление.** Если текст уже на языке перевода (например, вы выделили входящее
  сообщение на английском), он переводится на ваш язык (по умолчанию русский). Результат
  показывается в уведомлении.

## Готовые файлы

| Файл | Платформа |
|------|-----------|
| `release/TrayTranslator.exe` | Windows 10/11 x64. Один файл, ничего устанавливать не нужно |
| `release/traytranslator-linux-amd64` | Linux x86-64 (glibc ≥ 2.34) |

Скопируйте `TrayTranslator.exe` в любую папку и запустите. В трее появится синяя иконка «A→».

> Exe без цифровой подписи, поэтому при первом запуске SmartScreen может показать
> «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».

**Автозапуск (Windows):** нажмите `Win+R`, введите `shell:startup` и положите туда ярлык на exe.

## Меню в трее

* **Перевести и заменить (Alt+E)**
* **Язык перевода** — Русский (ru), English (en), Deutsch (de), Español (es), Français (fr),
  Українська (uk), 中文 (zh-CN), 日本語 (ja). Текущий язык отмечен галочкой, при смене появляется
  уведомление. По умолчанию выбран English.
* **Выучено фраз: N**
* **Открыть память (исправить перевод)** — открывает `translator-memory.json` в Блокноте.
* **Очистить память**
* **Выход**

## Как работает Alt+E

1. Сохраняется содержимое буфера обмена. На Windows сохраняются все форматы: текст, картинки,
   файлы, RTF.
2. Отправляется Ctrl+C. Если текст был выделен, переводится он.
3. Если ничего не выделено, отправляются Ctrl+A и Ctrl+C: выделяется всё поле ввода.
4. Программа ищет перевод в **памяти**, а если его там нет, запрашивает Google
   (`translate.googleapis.com`, `sl=auto`, таймаут 10 с).
5. Перевод кладётся в буфер, и отправляется Ctrl+V: выделенный текст заменяется переводом.
   Временный текст помечается так, чтобы не попасть в журнал буфера Windows (Win+V).
6. Исходное содержимое буфера восстанавливается.

Если поле пустое или приложение не отдаёт текст (таймауты 200 и 300 мс), программа ничего не
делает. Если нет интернета и фразы нет в памяти, появится уведомление.

## Обучение: память переводов

Файл `translator-memory.json` лежит рядом с exe:

```json
{
  "version": 1,
  "entries": [
    { "lang": "en", "src": "Привет", "dst": "Hello", "uses": 12, "last": "2026-09-25T10:00:00Z" }
  ]
}
```

* Запоминаются весь текст и каждое предложение отдельно. Поиск не учитывает регистр и лишние
  пробелы.
* **Исправить перевод:** в меню выберите «Открыть память», замените `dst`, например
  `"Hello"` → `"Hi"`, и сохраните файл. Программа подхватит правку со следующего Alt+E и будет
  всегда подставлять ваш вариант.
* Самые частые фразы стоят в начале файла. Хранится до 20 000 записей; редко используемые
  удаляются первыми.

## Настройки (`translator-config.json`)

```json
{ "target_lang": "en", "native_lang": "ru" }
```

* `target_lang` — на какой язык переводить (выбирается в меню).
* `native_lang` — ваш язык. На него переводится текст, который уже написан на `target_lang`.

Если папку exe нельзя изменять (например, `Program Files`), оба файла сохраняются в
`%APPDATA%\TrayTranslator\` или `~/.config/TrayTranslator/`.

## Крайние случаи и ограничения

* **Нужен интернет** для новых фраз. Выученные фразы переводятся офлайн.
* Эндпоинт Google неофициальный и бесплатный. При очень частых запросах Google может временно
  ограничить доступ (будет уведомление). Память заметно снижает число запросов.
* Один запрос — до 5000 символов. Длинный текст отправляется частями по границам предложений.
* **Окна с правами администратора (Windows, UIPI).** Если активное окно запущено от
  администратора, а переводчик нет, Windows блокирует эмуляцию клавиш. Появится уведомление.
  Решение: запускать TrayTranslator тоже от администратора.
* **Текст только для чтения** (веб-страница, чужое сообщение): заменить его нельзя, поэтому
  перевод показывается в уведомлении. Выделяйте такой текст мышью перед Alt+E, иначе Ctrl+A
  выделит всю страницу.
* **Во время перевода** (обычно меньше секунды) не переключайте окно.
* **Меню отпускания Alt.** В Windows отпускание Alt после хоткея активирует меню окна.
  Утилита подавляет это «маскирующей» клавишей и дожидается отпускания Alt/E.
* **Второй экземпляр** на Windows не запускается.
* **Alt+E занят другой программой** — при запуске появится уведомление.
* **macOS:** на первом запуске появится запрос разрешения «Универсальный доступ»
  (Accessibility). Хоткей там ⌥E, клавиши эмулируются как Cmd+A, Cmd+C и Cmd+V.
* **Linux Wayland:** хоткей регистрируется через портал `GlobalShortcuts` (KDE, GNOME 48+,
  Hyprland). Если портала нет, назначьте системное сочетание на команду
  `traytranslator-linux-amd64 --translate`. Клавиши эмулируются через `ydotool` (нужен
  `ydotoold`) или `wtype`, буфер обмена работает через `wl-clipboard`.
* **Linux X11:** нужен `xclip` или `xsel`, в GNOME — расширение AppIndicator.

## Сборка из исходников

Стек — **Go ≥ 1.24**. Весь код в одном файле `main.go` (плюс `go.mod`/`go.sum`). Платформенный
код (SendInput, XTest, CGEvent, буфер обмена Windows) находится в cgo-преамбуле, поэтому нужен
C-компилятор. Зависимости: `fyne.io/systray`, `github.com/atotto/clipboard`,
`github.com/godbus/dbus/v5`.

### Windows
Нужен MinGW-w64 gcc в `PATH`, например [WinLibs](https://winlibs.com/)
(`winget install BrechtSanders.WinLibs.POSIX.UCRT`) или MSYS2.
```bat
set CGO_ENABLED=1
go build -ldflags "-H windowsgui -s -w" -o TrayTranslator.exe .
```

Кросс-сборка через [zig](https://ziglang.org/) (так собран `release/TrayTranslator.exe`):
```bash
CGO_ENABLED=1 GOOS=windows GOARCH=amd64 CC="zig cc -target x86_64-windows-gnu" \
  go build -trimpath -ldflags "-H windowsgui -s -w -extldflags=-Wl,--subsystem,windows" \
  -o TrayTranslator.exe .
```

### Linux / macOS
```bash
go build -trimpath -ldflags "-s -w" -o traytranslator .
```
На Linux заголовки X11 не нужны: библиотеки подгружаются через `dlopen`. На macOS нужны
Xcode Command Line Tools.
